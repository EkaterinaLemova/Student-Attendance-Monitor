====================================================
   ЭдКонтроль — Контроль посещаемости обучающихся
   Инструкция по запуску в Visual Studio
====================================================

ЧТО НУЖНО УСТАНОВИТЬ:
1. Visual Studio 2022 (уже установлен)
2. .NET 8 SDK — скачать с: https://dotnet.microsoft.com/download/dotnet/8.0
   (нажмите "Download .NET 8.0 SDK" для Windows)
3. SQL Server — уже установлен (SSMS)

====================================================
ШАГ 1 — Настройка базы данных
====================================================
Откройте файл: appsettings.json

Найдите строку:
  "DefaultConnection": "Server=localhost;Database=EdControl;Trusted_Connection=True;TrustServerCertificate=True;"

Если ваш SQL Server называется иначе, замените "localhost" на имя вашего сервера
(имя сервера видно в SSMS при подключении).

====================================================
ШАГ 2 — Открыть проект
====================================================
1. Откройте Visual Studio
2. File → Open → Project/Solution
3. Выберите файл: EdControl.csproj
4. Нажмите "Open"

====================================================
ШАГ 3 — Установить пакеты
====================================================
В Visual Studio:
Tools → NuGet Package Manager → Package Manager Console

Введите команду:
  Update-Package

Нажмите Enter и подождите.

====================================================
ШАГ 4 — Создать базу данных
====================================================
В той же Package Manager Console введите:
  Add-Migration InitialCreate
  Update-Database

База данных EdControl создастся автоматически в SQL Server.

====================================================
ШАГ 5 — Запустить
====================================================
Нажмите зелёную кнопку "Run" (или F5)
Откроется браузер с приложением.
